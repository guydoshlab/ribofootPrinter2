# Transcriptome for *S. cerevisiae*
The FASTA files provided here can be used to run *ribofootPrinter2* on the yeast transcriptome.
These sequences in these files were taken from the R64 genome at SGD.
The annotation of CDS start and stop codons, and introns, was taken from R64-1-1. 
All genes are fully spliced.
To be included in the transcriptome, both 5' and 3' UTR annotation had to be available.
Two options are utilized to add UTR annotations:
## PMIDs: 31612944 and 23615609
This is referred to as Scer_R64-1-1. This annotation is included on SGD. Unlike the annotation available in the GTF, this utilizes the most abundant UTR length, rather than the longest UTR length.
This is the annotation for yeast grown in YPD.

## PMID: 29254944
This is referred to as Scer_R64-1-1_alt
